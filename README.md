# Portfolio Website

A modern personal portfolio website built with Next.js and Tailwind CSS, designed to showcase skills, experience, projects, and contact information in a clean and professional layout.

Live App: https://.vercel.app/

## Overview

This project is a responsive portfolio landing page for a developer or designer. It includes sections for:

- Hero section
- About me
- Skills
- Experience
- Projects
- Header navigation

The site is optimized for a polished presentation and smooth visual transitions using Framer Motion.
